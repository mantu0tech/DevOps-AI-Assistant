# 🚀 DevOps AI Assistant

An **AI-powered DevOps Assistant** built to help DevOps engineers, cloud learners, and interview aspirants with **real-world DevOps questions, troubleshooting, and interview preparation**.

🔗 **Live App:**  
👉 https://devops-ai-assistant.streamlit.app/

---

## 🧠 What is DevOps AI Assistant?

DevOps AI Assistant is a **DevOps-focused chatbot**, not a generic AI.  
It is designed specifically for:

- DevOps concepts
- Cloud & AWS
- Docker & Kubernetes
- CI/CD (Jenkins, GitHub Actions)
- Terraform & Infrastructure as Code
- Linux & Git
- DevOps interview preparation

---

## ✨ Key Features

### 💬 Chat Mode
- Ask DevOps-related questions
- Context-aware AI responses
- Error troubleshooting
- Optimized and fast responses
- DevOps topics only (no generic answers)

### 🎯 Interview Mode
- DevOps interview simulator
- Select topic & difficulty
- Multiple questions per session
- Strict evaluation
- Detailed feedback
- Progress tracking

### 🎨 UI & Experience
- Dark Mode 🌙
- Light (Purple) Mode 💜
- Clean & modern UI
- Mobile & desktop friendly
